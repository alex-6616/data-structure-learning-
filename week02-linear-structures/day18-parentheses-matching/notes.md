# Day 18: Parentheses Matching

> 学习阶段：第 3 阶段｜栈的应用  
> 对应章节：Ch3.3 括号匹配  
> 今日目标：用栈判断 `()[]{}` 是否正确嵌套

## 1. 算法

1. 遇到左括号：入栈；
2. 遇到右括号：检查栈是否为空；
3. 弹出栈顶并检查类型；
4. 扫描结束后，栈也必须为空。

```text
表达式：([{}])

字符    操作                 栈（左侧为栈底）
(       入栈                 (
[       入栈                 ( [
{       入栈                 ( [ {
}       与 { 匹配，出栈      ( [
]       与 [ 匹配，出栈      (
)       与 ( 匹配，出栈      空
```

## 2. 为什么需要栈

最后出现的左括号必须最先被匹配，这正是 LIFO：

```text
([{}])
  ▲▲
最内层括号最先闭合
```

## 3. 两类失败

- 提前遇到无对应左括号的右括号，如 `())`；
- 扫描结束后仍有左括号，如 `(()`；
- 类型不一致，如 `([)]`。

时间复杂度为 `O(n)`，最坏额外空间为 `O(n)`。
