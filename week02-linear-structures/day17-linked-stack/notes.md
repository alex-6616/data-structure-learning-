# Day 17: Linked Stack

> 学习阶段：第 3 阶段｜栈与队列  
> 对应章节：Ch3.3 链栈  
> 今日目标：用链表头部实现 `O(1)` 入栈和出栈

## 1. 为什么选择链表头部

```text
top
 │
 ▼
[30|next] ──▶ [20|next] ──▶ [10|NULL]
```

链表头部已知，不需要遍历。若把单链表尾部作为栈顶且没有前驱指针，出栈时寻找新尾结点会花费 `O(n)`。

## 2. 入栈

```text
入栈前：
top ──▶ [20] ──▶ [10] ──▶ NULL

node->next = top
top = node

入栈后：
top ──▶ [30] ──▶ [20] ──▶ [10] ──▶ NULL
```

## 3. 出栈

```text
出栈前：
top ──▶ [30] ──▶ [20] ──▶ [10] ──▶ NULL
          ▲
        target

target = top
top = target->next
free(target)

出栈后：
top ───────────▶ [20] ──▶ [10] ──▶ NULL
```

函数必须改变调用者的 `top`，因此可传入 `Node **top`。

## 4. 顺序栈与链栈

| 实现 | 优点 | 代价 |
|---|---|---|
| 顺序栈 | 连续、缓存友好、实现简单 | 固定容量时可能满 |
| 链栈 | 按需增长 | 每结点多一个指针，需要内存管理 |
