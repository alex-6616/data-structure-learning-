# Day 08: ADT and Linear Lists

> 学习阶段：第 2 阶段｜线性表  
> 对应章节：Ch3.1 ADT 与表  
> 今日目标：区分逻辑结构、存储结构和操作规则

## 1. 什么是线性表

线性表是由同类型元素组成的有限序列。除首元素外，每个元素有唯一前驱；除尾元素外，每个元素有唯一后继。

```text
a1 → a2 → a3 → ... → an
```

这里描述的是元素之间的逻辑关系，并没有规定它们在内存中如何保存。

## 2. 什么是 ADT

ADT（Abstract Data Type，抽象数据类型）说明：

- 数据对象是什么；
- 数据之间有什么关系；
- 允许执行哪些操作；
- 每个操作应产生什么结果。

```text
List ADT
├── Init
├── IsEmpty
├── Length
├── Find / Get
├── Insert
├── Delete
└── Destroy
```

ADT 只定义“做什么”。顺序表、链表等具体实现负责“怎么做”。

## 3. 三个层次

```text
逻辑结构：元素是一对一的线性关系
    │
    ├── 顺序存储：连续内存 + 下标
    └── 链式存储：离散结点 + 指针

操作规则：
一般线性表可在合法位置操作
栈只在一端操作
队列一端进入、另一端离开
```

数组不是线性表的同义词：数组提供连续存储空间；顺序表还维护有效长度，并定义增删查改等操作。

## 5. 易错点

- 把“线性”误解成地址一定连续；
- 把 ADT 当成某段固定代码；
- 把栈、队列和链表看成完全并列的概念；
- 忽略容量 `capacity` 与有效长度 `length` 的区别。
