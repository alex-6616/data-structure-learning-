# Day 09: Array List

> 学习阶段：第 2 阶段｜线性表  
> 对应章节：Ch3.1 顺序表  
> 今日目标：实现顺序表初始化、查找、插入与删除

## 1. 核心表示

```text
下标       0       1       2       3       4
        +------+------+------+------+------+
data    |  12  |  25  |  37  | 旧值 |      |
        +------+------+------+------+------+
                         ↑
                      length = 3
```

只有 `[0, length)` 属于当前顺序表。删除后数组中可以残留旧值，因为 `length` 已经改变了逻辑边界。

## 2. 插入

在下标 `1` 插入 `20`：

```text
[12][25][37][  ]
         37 ─────→
     25 ─────→
[12][20][25][37]
```

元素必须从后向前移动，否则原数据会被覆盖。

## 3. 删除

删除下标 `1`：

```text
[12][20][25][37]
         ← 25
              ← 37
[12][25][37][旧值]
             length = 3
```

元素从前向后覆盖，最后只需减小 `length`。

## 4. 复杂度

| 操作 | 复杂度 |
|---|---:|
| 按下标访问 | `O(1)` |
| 按值查找 | `O(n)` |
| 指定位置插入 | `O(n)` |
| 指定位置删除 | `O(n)` |
| 未扩容时尾插 | `O(1)` |

动态顺序表仍要求元素地址连续。扩容会申请更大的连续空间并复制旧元素；按倍数扩容时，连续尾插具有摊还 `O(1)` 代价。

## 5. 今日代码

- `static_array_list.c`：固定容量顺序表；
- `dynamic_array_list.c`：使用 `malloc/realloc` 的动态顺序表。

## 6. 易错点

- 插入允许 `index == length`，删除不允许；
- 插入前忘记判断表满；
- 移动方向或循环边界写反；
- 动态扩容时直接覆盖原指针，导致失败时内存丢失。
