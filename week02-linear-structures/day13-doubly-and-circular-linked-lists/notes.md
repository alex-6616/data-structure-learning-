## 1. 双向链表

```text
NULL ◀── [A] ⇄ [B] ⇄ [C] ──▶ NULL
```

在 `p` 与 `q` 之间插入 `node`：

```text
插入前： [p] ⇄ [q]

node->prev = p
node->next = q
p->next = node
q->prev = node

插入后： [p] ⇄ [node] ⇄ [q]
```

删除 `node`：

```text
删除前： [p] ⇄ [node] ⇄ [q]

p->next = q
q->prev = p
free(node)

删除后： [p] ⇄ [q]
```

核心不变量：对任意相邻结点，若 `p->next == q`，则应有 `q->prev == p`。

## 2. 循环链表

带头结点的单向循环链表：

```text
head ──▶ [dummy] ──▶ [A] ──▶ [B] ──▶ [C]
          ▲                              │
          └──────────────────────────────┘
```

尾结点指向 `head`，因此遍历终止条件是 `current == head`，而不是 `current == NULL`。

## 3. 适用场景

- 双向链表：需要频繁向前移动或已知结点直接删除；
- 循环链表：轮转调度、循环播放、约瑟夫问题；
- 循环双向链表：实现 Deque 或 LRU 等需要两端操作的结构。
