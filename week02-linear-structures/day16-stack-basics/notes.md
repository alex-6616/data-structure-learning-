## 1. 栈的规则

栈只允许在栈顶一端插入和删除：

- `Push`：入栈；
- `Pop`：删除并返回栈顶；
- `Top/Peek`：只读取栈顶；
- LIFO：Last In, First Out。

```text
Push 10      Push 20      Push 30       Pop

               top          top          top
                ↓            ↓            ↓
+----+        +----+       +----+       +----+
| 10 |        | 20 |       | 30 |       | 20 |
+----+        +----+       +----+       +----+
              | 10 |       | 20 |       | 10 |
              +----+       +----+       +----+
                           | 10 |
                           +----+
```

## 2. 顺序栈表示

本日约定 `top` 指向下一个可插入位置：

```text
空栈：top = 0

下标       0       1       2       3
        +------+------+------+------+
data    |  10  |  20  |      |      |
        +------+------+------+------+
                      ↑
                    top = 2

栈顶元素：data[top - 1]
```

因此：

- 入栈：先写入 `data[top]`，再 `top++`；
- 出栈：先 `top--`，再读取 `data[top]`；
- 判空：`top == 0`；
- 判满：`top == capacity`。

另一种约定令 `top` 指向当前栈顶，空栈为 `-1`。两种都可以，但一份代码中不能混用。

## 3. 复杂度

`Push`、`Pop` 和 `Top` 都是 `O(1)`。出栈后不必清零数组元素，移动 `top` 已经改变了逻辑边界。
