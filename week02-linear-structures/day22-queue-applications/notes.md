## 1. 排队模拟

顾客按到达顺序入队，服务台每次处理队头：

```text
时间 0：队列空
时间 1：A 到达      front [A] rear
时间 2：B、C 到达   front [A][B][C] rear
时间 3：A 完成      front [B][C] rear
```

队列使“先到先服务”自然成立。

## 2. BFS

BFS 使用队列按层扩展：

```text
图：
    A
   / \
  B   C
 / \   \
D   E   F

队列变化：
[A]
弹 A，压 B、C      [B, C]
弹 B，压 D、E      [C, D, E]
弹 C，压 F         [D, E, F]

访问顺序：A, B, C, D, E, F
```

基本过程：

1. 起点入队并标记；
2. 队头出队；
3. 把所有未访问邻居标记后入队；
4. 重复直到队空。

必须在“入队时”标记，避免同一顶点被不同前驱重复入队。

## 3. 双端队列

Deque 允许两端插入和删除：

```text
Push / Pop                         Inject / Eject
    ⇄  [A] [B] [C]  ⇄
       队头     队尾
```

它可模拟栈或队列，但仍不允许在中间任意位置操作。
