## 1. 后缀表达式

中缀：`(3 + 4) * 2`  
后缀：`3 4 + 2 *`

后缀表达式不需要括号，也不需要在求值时比较运算符优先级。

## 2. 求值过程

```text
Token   操作                                  栈
3       压入 3                               [3]
4       压入 4                               [3, 4]
+       弹出 4、3，计算 3+4，压入 7          [7]
2       压入 2                               [7, 2]
*       弹出 2、7，计算 7*2，压入 14         [14]
```

遇到二元运算符：

```text
right = pop()   // 先弹出右操作数
left  = pop()   // 后弹出左操作数
push(left operator right)
```

对减法和除法，顺序尤其重要。

## 3. 合法性检查

- 操作数入栈；
- 运算符出现时栈中至少有两个数；
- 除数不能为零；
- 扫描结束时栈中必须恰好剩一个结果；
- 非法 token 应立即报错。
