## 1. 反转单链表

必须保留三个位置：

```text
previous    current       next
    │          │            │
    ▼          ▼            ▼
  NULL       [A] ────────▶ [B] ────────▶ [C] ──▶ NULL
```

保存 `next` 后反转当前指针：

```text
previous    current       next
    │          │            │
    ▼          ▼            ▼
  NULL ◀───── [A]           [B] ────────▶ [C] ──▶ NULL
```

再整体向前推进：

```text
             previous     current
                 │           │
                 ▼           ▼
  NULL ◀─────── [A]         [B] ────────▶ [C] ──▶ NULL
```

核心不变量：`previous` 前方已经反转完成，`current` 及其后方仍保持原顺序。

## 2. 合并两个有序链表

```text
L1: 1 → 4 → 7
L2: 2 → 3 → 8

每次比较两个当前结点，把较小者接到结果尾部：

result: 1 → 2 → 3 → 4 → 7 → 8
```

使用 dummy 头结点可避免结果表第一个结点的特殊处理。合并时可以复用原结点，不需要重新申请所有结点。

## 3. 复杂度

- 反转：时间 `O(n)`，额外空间 `O(1)`；
- 合并：时间 `O(m+n)`，若复用结点则额外空间 `O(1)`。
