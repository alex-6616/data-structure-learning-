# Day 21: Queues and Circular Queues

> 学习阶段：第 3 阶段｜栈与队列

> 今日目标：统一 `front/rear` 约定并理解取模

## 1. 队列规则

队列先进先出（FIFO）：

```text
出队方向                                  入队方向
   ◀── front [10] [20] [30] rear ──▶
```

## 2. 假溢出

普通数组队列只向右移动下标：

```text
下标       0       1       2       3       4
        +------+------+------+------+------+
        | 旧值 | 旧值 |  30  |  40  |  50  |
        +------+------+------+------+------+
                      ↑                    ↑
                    front                rear
```

前方虽有空位，但 `rear` 到达末尾，形成假溢出。

## 3. 循环队列约定

本日约定：

- `front` 指向当前队头；
- `rear` 指向下一个可插入位置；
- 留一个空位区分队空和队满。

```text
队空：front == rear
队满：(rear + 1) % capacity == front
长度：(rear - front + capacity) % capacity
```

```text
容量 6，最多保存 5 个元素：

下标       0       1       2       3       4       5
        +------+------+------+------+------+------+
        |  50  |      |      |  20  |  30  |  40  |
        +------+------+------+------+------+------+
              ↑             ↑
             rear          front

逻辑顺序：20 → 30 → 40 → 50
```

出队时先读取 `data[front]`，再移动 `front`。若先移动，读到的已经是新队头；用 `front - 1` 在绕回时还会出现负下标。

## 4. 链队列

```text
front                                  rear
  │                                      │
  ▼                                      ▼
[dummy|next] ──▶ [10|next] ──▶ [20|NULL]
```

入队在尾部插入；出队删除头结点后的首元结点。删除最后一个有效结点后，`rear` 必须重新指向头结点。
