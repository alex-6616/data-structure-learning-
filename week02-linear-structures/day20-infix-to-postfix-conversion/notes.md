# Day 20: Infix to Postfix Conversion

> 学习阶段：第 3 阶段｜栈的应用  
> 对应章节：Ch3.3 中缀转后缀  
> 今日目标：用运算符栈处理优先级和括号

## 1. 基本规则

- 操作数直接输出；
- 左括号入栈；
- 右括号出现时，弹出到左括号为止；
- 普通运算符入栈前，先弹出栈中优先级不低于它的运算符；
- 扫描结束后弹出剩余运算符。

## 2. 过程

中缀：`A + B * C`

```text
扫描项    输出       运算符栈
A         A          空
+         A          +
B         AB         +
*         AB         + *
C         ABC        + *
结束      ABC*+      空
```

`*` 的优先级高于 `+`，所以它不会迫使 `+` 出栈。

中缀：`(A + B) * C`

```text
扫描项    输出       运算符栈
(         空         (
A         A          (
+         A          ( +
B         AB         ( +
)         AB+        空
*         AB+        *
C         AB+C       *
结束      AB+C*      空
```

## 3. 左结合

对 `+ - * /`，相同优先级时先弹栈，体现左结合：

```text
A - B - C  ==>  AB-C-
```
