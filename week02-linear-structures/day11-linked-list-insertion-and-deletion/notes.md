## 1. 在 `p` 后插入

插入前：

```text
p
│
▼
[A|next] ─────────▶ [B|next]
```

先执行 `node->next = p->next`：

```text
p                     node
│                       │
▼                       ▼
[A|next] ──────▶ [B|next]
                 ▲
                 └──── [X|next]
```

再执行 `p->next = node`：

```text
[A|next] ──▶ [X|next] ──▶ [B|next]
```

如果先覆盖 `p->next`，原后继地址会丢失。

## 2. 删除 `p` 的后继

```text
删除前：
p          target
│             │
▼             ▼
[A|next] ──▶ [X|next] ──▶ [B|next]

target = p->next
p->next = target->next
free(target)

删除后：
[A|next] ─────────────▶ [B|next]
```

链表删除不仅改变逻辑连接，还要释放动态分配的结点。

## 3. 为什么有时需要二重指针

不带头结点时，删除首元结点会改变 `head` 本身：

```text
删除前：head ──▶ [A] ──▶ [B]
删除后：head ──────────▶ [B]
```

函数要修改调用者保存的头指针，因此可以传入 `Node **head`。带头结点时，常通过固定的 dummy 结点避免许多特殊分支。

## 4. 复杂度条件

“链表插入、删除是 `O(1)`”必须满足：已经获得目标位置或其前驱。若先按值查找，完整操作仍是 `O(n)`。
